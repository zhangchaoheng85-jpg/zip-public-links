# zip-public-links

Public GitHub storage for ZIP files dropped into `C:\Users\Administrator\Desktop\图片`.

Run `sync-zips.ps1` to:

1. Copy new or changed `.zip` files into `uploads/`
2. Regenerate `links.csv` and `links.txt`
3. Use the public GitHub URLs for sharing or bulk import

`links.csv` includes both the GitHub page URL and the raw download URL for each file.
